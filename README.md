# All code relevant for the (D)NumRisk project/study

This Github repo contains all the code that is used for the (D)NumRisk study

## Installation

Clone this git repository

git clone git@github.com:mrenke/numrisk.git

install via 
`python setup.py install`

## Usage

* prior analysis that informed the study are in `prior_behavior_analysis`
* experimental paradigms are in `experiment` (main magnitude compariosn task done in the scanner) & `experiment_risk` (risky choice task done outside the scanner with eyetracking)
* main data analysis code in `numrisk` , for both, behavioral and neural modelling
